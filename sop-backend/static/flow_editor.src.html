선 연결 방법
노드의 위·오른쪽·아래·왼쪽 중앙 점에서 마우스를 누른 채 다른 노드의 연결점까지 드래그하세요.

Decision에서 연결한 선은 오른쪽 속성창에서 조건명을 입력할 수 있습니다.

연결선을 클릭하면 오른쪽에서 꺾은 선 / 직선을 선택할 수 있습니다. 꺾은 선은 파란 조절점을 드래그해 경로를 수정할 수 있습니다.

박스 크기는 고정이며, 일반 노드는 Font Size를 조절할 수 있습니다. SEQ 노드는 Number / Role Owner / Action 제목 / Action 내용 / System / Manual 글자 크기를 각각 조절할 수 있습니다.

Name / Action / Role Owner 입력창에서는 Enter로 줄바꿈할 수 있습니다.

상단의 − / ＋ 버튼으로 플로우를 확대·축소할 수 있고, 격자 버튼으로 배경선을 켜거나 끌 수 있습니다. PNG 버튼으로 현재 플로우를 이미지로 저장할 수 있습니다.

오른쪽 구분선을 드래그하면 입력창 너비를 조절할 수 있습니다.

노드 번호는 오른쪽 속성창에서 직접 변경할 수 있습니다. 삭제된 번호는 다음 노드 추가 시 다시 사용됩니다.
